# Collatz-conjecture-calculation

C program used for the numerical calculations in the study:
**"Iterative calculation values in Collatz conjecture eventually reach 1 as if walking across multiple tightropes."**

## How to run
- Language: C
- Import the program into Visual C++, and then run it.

## Citation
The relevant paper is available: the Zenodo DOI (10.5281/zenodo.19028464). A citation example is as follows: Shiraishi, F. (2026). Iterative calculation values in the Collatz conjecture eventually reach 1 as if walking across tightropes. https://doi.org/10.5281/zenodo.19028464.
